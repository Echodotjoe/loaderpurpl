# 🍇 PURPLE VAULT - SWF & HTML5 Game Hub Repository

Welcome to **Purple Vault**, a modern retro-styled web game portal designed to load and play both **Flash (.swf)** games (powered by the integrated [Ruffle](https://ruffle.rs/) emulator) and **HTML5** games directly from an `./items/` directory.

---

## 🚀 Quick Start & Deployment Guide

### 1. Adding Games to your Hub
1. Place all your `.swf` and `.html` game files into the `items/` folder in this repository.
   - Example path for Flash: `items/space_shooter.swf`
   - Example path for HTML5: `items/retro_runner.html`
2. Open `index.html` in your browser or click **"Add Game"** in the top navigation bar to register your game filenames into the list!

### 2. Host directly on GitHub Pages
1. Push this repository to GitHub.
2. Go to **Settings > Pages**.
3. Set the source branch to **main** (or `master`) / root (`/`).
4. Click **Save**. Your Purple Vault portal will be live on the web instantly!
